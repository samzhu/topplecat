# Security Policy

## Supported Version

Before 1.0, security fixes target the latest code on `main`.

## Report a Vulnerability

Use GitHub private vulnerability reporting from the repository **Security** tab.
Do not put an undisclosed vulnerability, reviewer-only data, credentials, or
exploit details in a public issue.

If private reporting is unavailable, open a public issue that asks for a private
contact channel without including vulnerability details.

Include:

- affected version or commit;
- reproduction steps;
- security impact;
- a minimal proof of concept when available.

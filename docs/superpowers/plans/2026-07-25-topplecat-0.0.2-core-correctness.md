# ToppleCat 0.0.2 Core Correctness Implementation Plan

> **For the downstream implementation agent:** Use the
> `test-driven-development` skill for every behavior change and the
> `verification-before-completion` skill before claiming completion. Implement
> this as one integrated 0.0.2 delivery with the reviewable commits listed
> below. Do not push, tag, publish, or open a pull request.

**Goal:** Prevent false trustworthy verdicts caused by read-only expected
values or JSON number representation, let an authorized reviewer safely evolve
an existing escrowed suite, and make the mutation gate explicitly measure the
public executable contract.

**Architecture:** Keep Java acceptance tests and typed JSON/YAML case rows as
the only authoritative contract. Put recursive value comparison in the JUnit
module, custody transaction behavior in core, and Gradle orchestration in the
existing plugin. Keep PIT on the ordinary `test` source set and treat reports
and JSON as evidence projections only.

**Tech stack:** Java 25, JUnit Jupiter and Platform Launcher, Jackson 3
`JsonNode`, Gradle Java Plugin/TestKit, PIT and the SolidSoft Gradle PIT plugin.

**Step 2: Add one package-private recursive comparator**

Implement this shape without epsilon or conversion through `double`:

```java
final class JsonContractEquality {
    private JsonContractEquality() {
    }

    static boolean equivalent(JsonNode expected, JsonNode actual) {
        if (expected == actual) {
            return true;
        }
        if (expected == null || actual == null) {
            return false;
        }
        if (expected.isNumber() && actual.isNumber()) {
            return expected.decimalValue().compareTo(actual.decimalValue()) == 0;
        }
        if (expected.isObject() && actual.isObject()) {
            var expectedNames = new TreeSet<>(expected.propertyNames());
            var actualNames = new TreeSet<>(actual.propertyNames());
            return expectedNames.equals(actualNames)
                    && expectedNames.stream()
                    .allMatch(name -> equivalent(expected.get(name), actual.get(name)));
        }
        if (expected.isArray() && actual.isArray()) {
            if (expected.size() != actual.size()) {
                return false;
            }
            for (int index = 0; index < expected.size(); index++) {
                if (!equivalent(expected.get(index), actual.get(index))) {
                    return false;
                }
            }
            return true;
        }
        return expected.equals(actual);
    }
}
```

In `ToppleCase.verify`, replace `expected.equals(actualNode)` with

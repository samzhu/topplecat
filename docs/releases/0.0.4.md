# ToppleCat 0.0.4

> Release: 0.0.4 · 2026-07-27

## Highlights

- The managed PIT producer now targets every compiled public canonical
  `@ToppleTest` declaring class. ToppleCat reads the compiler-emitted contract
  descriptors and configures PIT `targetTests` before the producer runs, so a
  production package and its public test package no longer need to share a
  package name for mutation verification to be meaningful.

- Consumer PIT choices remain authoritative. An explicitly configured
  `targetTests` is preserved, and a custom mutation producer is left untouched.
  If a usable report does not exercise a canonical acceptance test, the
  mutation gate records `FAIL`; ToppleCat never silently broadens the target or
  treats that report as a pass.

- Missing, malformed, or interrupted PIT output is recorded as
  `MUTATION=INCOMPLETE`. The aggregate verdict cannot become `PASS` from an
  incomplete current-run gate, and stale mutation artifacts are never reused.
  Safe agent feedback uses a generic public-contract diagnostic without
  exposing reviewer test names, source paths, or raw PIT failures.

- Reviewer-only JSON/YAML rows may reuse the public canonical `@ToppleTest`; when
  no hidden Java test exists, the canonical execution is aggregated as the
  reviewer retest. Java helper sources without executable JUnit methods are compiled
  but do not count as hidden tests. Hidden Java tests remain independent, and an
  enabled retest with no rows or Java tests stays `INCOMPLETE`.

## Upgrade note

No consumer configuration is required for the managed `pitest` producer. The
first run after upgrading may take longer while compiler descriptors and the PIT
mutation matrix are produced. If your build deliberately configures PIT
`targetTests`, keep that setting; ToppleCat preserves it and the resulting
report must cover the public canonical contract for mutation to pass.

Custom mutation producers remain responsible for their own test targeting and
report completeness. A custom producer that emits no usable report now yields
`INCOMPLETE`, not evidence that mutation passed.

## Boundary

The default mutation gate measures public executable contract strength. Reviewer
rows and reviewer-only JUnit tests remain separate hidden-retest evidence and
cannot improve the default PIT score. Compiler descriptors identify canonical
classes and methods; generated reports and JSON remain evidence, not another
authoring language or source of truth.

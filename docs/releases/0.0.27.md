# ToppleCat 0.0.27

ToppleCat 0.0.27 makes the public project site’s animated demonstration more stable and easier to inspect on desktop and mobile.

## See a steadier product demonstration

The hero cat poses now share one grounded paw anchor, removing small horizontal jumps between animation frames and simplifying the asset contract. The demonstration report dialog can use more of the viewport when opened, while the secondary examples fit their four-entry layout cleanly.

## Upgrade

Update the Gradle plugin and `topplecat-junit` dependency to `0.0.27`. There are no Java or verification-contract changes in this release.

The `--ac` selection surface, the complete executable contract, and the
`toppleCatSeal` custody workflow are unchanged.

## Requirements

Java 25 and a compatible Gradle version remain required.

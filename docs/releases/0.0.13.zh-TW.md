# ToppleCat 0.0.13

ToppleCat 0.0.13 讓 Verification Report 中 Property 的完成數量忠實反映本次執行真正能證明的內容，因此不完整或不相符的 lifecycle evidence 不會再灌高交付範圍中的完成數。

## 只呈現有完整證據的 Property 執行

過去，只有 terminal event、事件重複、事件來自其他 run，或契約 identity 不相符的 Property，仍可能增加完成數。現在 Verification Report 只有在 Current-run Evidence 中，對同一個已選且 sealed 的 Property，找到恰好一個 `STARTED` 事件，並依序接著恰好一個相符的 terminal event，且 run ID、Acceptance Condition ID、完整 Java method identity 與 source digest 都一致時，才會計為完成。

完成與結果是分開的事實。有效的 `COMPLETED_PASS`、`COMPLETED_COUNTEREXAMPLE` 或 `COMPLETED_INCOMPLETE` lifecycle 都算完成；`PROPERTY` Gate 仍依結果與既有 evidence checks 分別維持 `PASS`、`FAIL` 或 `INCOMPLETE`。

## 升級步驟

本版沒有 breaking Java API、evidence schema、Gradle DSL 或設定變更，使用者不需要修改 executable contract。升級時，請將 Gradle plugin 與 `topplecat-junit` dependency 更新為 `0.0.13`。

## 環境需求

JDK、Gradle、JUnit 與 PIT 需求不變。正式 Verify 仍管理既有 PIT 版本，報告 bundle 仍可離線使用。

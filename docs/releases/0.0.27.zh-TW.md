# ToppleCat 0.0.27

ToppleCat 0.0.27 讓公開網站的動畫示範更穩定，也更容易在桌面與手機上檢視。

## 看見更穩定的產品示範

Hero 中三個貓咪姿勢現在共用同一個落地腳掌定位點，移除動畫影格之間細微的水平跳動，也讓素材規格更簡單。開啟示範報告對話框時可以使用更多視窗高度；次要示範項目也會整齊地排列成四項。

## 升級方式

將 Gradle plugin 與 `topplecat-junit` dependency 更新為 `0.0.27`。本版沒有 Java 或驗證合約變更。

`--ac` 選取介面、完整可執行契約與 `toppleCatSeal` 保管流程都維持不變。

## 環境需求

Java 25 與相容的 Gradle 版本需求維持不變。

# ToppleCat 0.0.16

ToppleCat 0.0.16 讓 Reviewer 能用繁體中文閱讀兩份私有 HTML 報告，不必在心裡翻譯
可執行契約、本次執行證據或 Implementation Agent 的安全回饋。

## 以選定語言閱讀 Reviewer 報告

Spec Review 與 Verification Report 現在支援每次執行選擇
`--language en` 或 `--language zh-TW`；預設仍是英文。

例如，Reviewer 可用以下命令準備繁體中文的 Spec Review：

```bash
./gradlew toppleCatReview --spec specs/checkout/spec.md --language zh-TW
```

`toppleCatSeal`、`toppleCatReseal` 與 `toppleCatVerify` 也支援相同選項。Seal 與
Reseal 會把選擇傳給相依的 Spec Review，因此穩定位置的審閱報告會維持指定語言。

繁體中文會本地化 ToppleCat 自己的標題、控制項、無障礙文字、說明、空白狀態與
fallback。報告仍可離線使用、自含資源、正確跳脫內容並受 CSP 保護。

## 契約與證據維持原樣

`@DisplayName`、`@As`、Property 標題、已選 Markdown、Typed Case Row 內容、原始
失敗、AC ID、Gate 名稱與 verdict，以及 PIT producer 結果都不會被翻譯。作者寫下的
繁體中文會一路保留在 compiler descriptor、runtime narrative、報告 JSON 與 HTML。

語言選擇只影響呈現，不會改變 Delivery Scope、Executable Contract、Mechanical Seal、
Gate verdict、Current-run Evidence 或 `agent-feedback.json`。

## 升級步驟

1. 將 Gradle plugin 與 `topplecat-junit` dependency 更新為 `0.0.16`。
2. 原有命令不必改動；Reviewer 想以繁體中文閱讀報告時，加上 `--language zh-TW`。
3. 只能使用 `en` 或 `zh-TW`；不支援或空白的明確值會在正式 Verify 工作開始前失敗。

## 環境需求

Java 25 與既有相容的 Gradle、JUnit 需求不變。沒有使用翻譯服務、字型下載、瀏覽器
語言、環境變數或持久的 Gradle 設定。

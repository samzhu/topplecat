# ToppleCat 0.0.14

ToppleCat 0.0.14 把 AI 交付的審閱流程整理成兩個清楚的時間點：交付前讀完整的
可執行契約，正式驗證後查看問題優先的報告，再由人類決定是否接受。

## 升級：停止使用已移除的公開 HTML

如果從上一個正式發布的 0.0.10 升級，請注意
`build/topplecat/reports/public/` 已不再產生。Implementation Agent 仍會拿到原本的
公開 Java/JUnit 契約與安全的 `agent-feedback.json`，沒有替代的公開 HTML。

直接使用舊 `SpecView` projection 的程式必須移除這項整合。讀取報告 `data.json`
的 reviewer 工具必須改用 `topplecat.review-view.v7` 與
`topplecat.verification-view.v9`。ToppleCat 不提供舊版 projection 的相容 reader
或雙寫入機制。

公開 Java/JUnit authoring API、Gradle task 名稱、`--spec` 選取方式、六個 Gate
名稱與 machine evidence schema，除此之外沒有改變。

## 交付前後都審閱同一份契約

`toppleCatReview` 會在實作交付前寫出 reviewer-only 的 **Spec Review**。內容包括
每份完整的已選 Markdown、圖表、由 compiler 描述的 Scenario、公開與 reviewer
Typed Case Rows、Properties，以及 Acceptance Method 原始碼。它不執行驗證，也不
判斷上游 Spec 是否完整。

正式 Verify 會寫出 reviewer-only 的 **Verification Report**。報告先呈現 ToppleCat
的交付建議與具體問題，再分開列出 Contract Integrity、Public Acceptance、Hidden
Tests、Property-Based Testing 與 Mutation Testing。這些結果不會混成品質分數；
是否接受交付，最後仍由審閱者決定。

兩份報告都能離線閱讀，也不依賴外部資源。不支援或不安全的內容會被跳脫；本機
圖片或圖表無法呈現時，報告會留下看得見的替代說明，不會直接省略。

## Property 完成數只計入完整證據

Verification Report 只會在 **Current-run Evidence** 中找到恰好一個 `STARTED`
event，後面接著一個 run ID、Acceptance Condition、完整 Java method identity 與
source digest 都相符的 terminal event 時，才把已選 Property 算成完成。重複、
來自其他 run 或不完整的 lifecycle evidence 都不能增加完成數。

完成與結果仍是兩件事。有效的通過、counterexample 或 incomplete terminal event
都算已完成證據；`PROPERTY` Gate 仍依照實際結果呈現對應狀態。

## 產品邊界有固定文件可查

公開的產品定義現在明確寫出 ToppleCat 從哪裡開始、到哪裡結束。開發者或
Reviewer 在送出 pull request 前，用它檢驗 AI agent 的完成宣稱並閱讀人類報告。
Spec 選取、CI 或 workflow 放置位置、交付歷史、組織核准、一般 QA 與專案自己的
PIT 工作，仍由團隊負責。

Repository contributor 也有完整索引的設計生命週期與專案自有的 product-design
skill。已接受但尚未實作的決策放在 `docs/design/`；完成後則合併到目前文件並刪除，
避免留下兩份互相衝突的產品說明。

## 升級步驟

1. 將 Gradle plugin 與 `topplecat-junit` dependency 更新為 `0.0.14`。
2. 停止發布或解析 `reports/public`；如果 reviewer 工具有讀取報告資料，請改用目前
   的 projection。
3. Restore reviewer custody，接著執行 Check、Review、Reseal，最後才 Verify。
   Mechanical Seal 只適用目前版本。

## 環境需求

Java 25 與既有相容的 Gradle、JUnit 需求沒有改變。正式 Verify 仍由 ToppleCat
管理 PIT 1.25.5，報告 bundle 仍可離線使用。

## 完整變更

上一個正式發布的 GitHub Release 是 0.0.10。0.0.11、0.0.12 與 0.0.13 只有 tag，
沒有發布為 GitHub Release，因此本版說明一併包含其報告與證據變更。

# ToppleCat 0.0.7

0.0.7 是唯一支援的 ToppleCat 版本。這是破壞性版本，只有一套可執行驗收撰寫模型，
且審閱者保管資料只接受目前版本。

## 使用唯一的 Scenario API

每個 `@ToppleAcceptanceTest` 都接收 `ToppleCase`、一個 `ToppleScenario` 與具體的
能力 `ToppleStage` 參數。方法直接選取 Given、When、Then 與 And Step；同一個
Typed Case Row 的狀態由 Stage 內的一般 Java 欄位保存。

舊的欄位 annotation、狀態傳遞 annotation、fluent helper、runtime recording helper、
sentence helper 與替代的驗收名稱都已移除。不保留相容層或其他撰寫方式。

## 讓三套 safeguard 各自獨立

隱藏測試、突變測試與性質導向測試各有自己的輸入、task、policy、evidence 與 gate。
性質是公開且有界的不變量；它不使用隱藏測試，也不會補足隱藏測試 coverage 或
突變分數。PIT 仍是預設的突變測試 producer。

## 封印目前的審閱資料

交付前執行 `toppleCatSeal`；經授權的審閱者修改後執行 `toppleCatReseal`。approval
與 custody 只讀取 0.0.7 schema，請為這個版本建立新的審閱者狀態。審閱者保管是
明文的機械化儲存；最終判定採用本次執行證據，而不是封存檔。

## 更新的指引

根目錄 `CONTEXT.md` 是唯一的 glossary。文件、samples、網站與
`topplecat-acceptance` skill 都使用相同術語與 Scenario API。這個 skill 會協助把
選定的 Acceptance Condition 寫成 Java/JUnit 方法、公開與審閱者 Typed Case Row，
以及選用的 Property；ToppleCat 的執行與結果接受仍由人類或外部工作流程負責。

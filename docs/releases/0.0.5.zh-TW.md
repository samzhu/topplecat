# ToppleCat 0.0.5

> 交付前更容易確認真正會執行的合約，也能從剛 clone 下來的 sample 直接開始試用。

## 為什麼值得升級

- 審閱合約頁現在會把每個驗收條件放在真正會由 JUnit 執行的主要測試方法旁邊。
  公開案例先出現，獨立設計的審閱者專用檢查會清楚標示；畫面的對比也提高了，
  看報告比較不吃力。
- JUnit 與 Spring Boot 的 sample 現在可以直接在各自目錄執行 `./gradlew`。
  一般互動試用會使用正式發佈的套件；只有要驗證這個原始碼工作副本的 demo 才會
  使用 Maven Local。
- 新增的常見問題整理了 Java/JUnit 合約的做法、為什麼 ToppleCat 不需要
  Cucumber 或 `.feature`，以及 PIT、BDD 和 JGiven 與本專案的關係。

## 升級方式

大多數專案只要把 Gradle 外掛與 `topplecat-junit` 的版本更新成 `0.0.5`。

```kotlin
id("io.github.samzhu.topplecat") version "0.0.5"
```

## 相容性

沒有使用者可見的破壞性變更。既有合約、審閱者保管流程與驗證關卡的行為都維持不變。

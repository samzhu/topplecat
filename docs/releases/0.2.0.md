# ToppleCat 0.2.0

ToppleCat 0.2.0 lets Java teams run the verification gate on JDK 21 while
keeping Java 25 as the primary build and release environment.

## Adopt ToppleCat without a Java 25 runtime

The 0.1.0 artifacts required Java 25. In 0.2.0, the four published modules,
Gradle plugin, report, JUnit integration, and formal verification flow run on
JDK 21 and JDK 25. The single artifact family targets Java 21 bytecode and is
built with JDK 25 using an explicit `--release 21` policy.

## Keep Java 17 source projects on a supported execution JDK

A consumer project may continue to target Java 17 source, as well as Java 21 or
Java 25 source, when its Gradle/plugin execution environment uses JDK 21 or
JDK 25. A JDK 17-only environment cannot load or run the Java 21-targeted
ToppleCat artifact. Java 25 remains a supported runtime and consumer source
line.

## See the release boundary in CI and artifacts

The release checks include a JDK 21 minimum line, a JDK 25 primary release
line, a JDK 17 unsupported-runtime guard, and explicit consumer source/runtime
fixtures. The release gate scans every class in all four module JARs and their
Gradle publication metadata, rejecting newer or preview bytecode before
publication.

## Learn the workflow in both languages

The public project site now provides bilingual product documentation and a
standalone JUnit cart-orders learning project with five synthetic safeguard
demonstrations. The demonstrations remain explanatory material; they are not
evidence or approval for an actual delivery.

## Upgrade

Update the Gradle plugin and `topplecat-junit` dependency from `0.1.0` to
`0.2.0`. Run the build with JDK 21 or JDK 25. If a project carries reviewer
custody from 0.1.0, restore it, run Check and Review, and reseal it under the
0.2.0 policy before formal Verify; reviewer custody is current-version-only.

No Java 17 source rewrite is required when the consumer execution environment
uses JDK 21 or JDK 25.

`toppleCatSeal` still seals the complete executable contract. A quick scoped
verification may use `--ac`, while CI should continue to run the complete
unscoped command.

## Requirements

ToppleCat runtime and Gradle/plugin execution require JDK 21 or JDK 25. The
maintainer build and Central publication preflight use JDK 25. Consumer source
may target Java 17, 21, or 25 only when ToppleCat executes on JDK 21 or JDK 25.

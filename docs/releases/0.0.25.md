# ToppleCat 0.0.25

ToppleCat 0.0.25 lets a Reviewer get fast, formal evidence for just-finished
Acceptance Conditions without mistaking that result for a complete-project
verification.

## Verify exactly the ACs you just changed

`toppleCatVerify` still verifies the complete executable contract when invoked
without a selection, which remains the normal CI command. For a quicker formal
check, a Reviewer can now select either repository Spec documents or repeated
`--ac AC-...` IDs, never both:

```bash
./gradlew toppleCatVerify --spec specs/checkout/spec.md
./gradlew toppleCatVerify --ac AC-CHECKOUT-THRESHOLD --ac AC-CHECKOUT-VIP
```

The selected run keeps its public acceptance, Hidden Tests, Property-Based
Testing, and Mutation Testing safeguards. Its Verification Report names the
selection source and IDs. A scoped `PASS` now explicitly says that it covers
only those ACs and does not mean the complete executable contract passed.

## Keep custody and integrity project-wide

`toppleCatSeal` and `toppleCatReseal` now always handle the complete executable
contract and verification policy. They reject `--spec` and `--ac`, avoiding the
misleading idea that reviewer custody or a Mechanical Seal can belong to just
one feature. Contract Integrity likewise compares the complete contract even
when a later Verify run is scoped.

## Upgrade from 0.0.24

1. Update the Gradle plugin and `topplecat-junit` dependency to `0.0.25`.
2. Remove `--spec` and `--language` from Seal and Reseal commands. Use
   `toppleCatReview --language zh-TW` when a localized Review is wanted.
3. Use unselected `toppleCatVerify` in CI. For local feature evidence, select
   either `--spec` paths or repeated `--ac` IDs.
4. Create a current Mechanical Seal before formal Verify. Existing custody and
   approval state is current-version-only; restore it, then Check, Review, and
   Reseal when updating an existing reviewer suite.

## Requirements

Java 25 and a compatible Gradle version remain required. The public Java/JUnit
authoring API is unchanged; this release changes Gradle task behavior,
reviewer-report presentation, and the current Mechanical Seal format.

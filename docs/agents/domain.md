# Domain docs

ToppleCat is a single-context repository. Read the root `CONTEXT.md` before
exploring or writing specifications, tickets, tests, or implementation plans.

Use the formal terms from `CONTEXT.md` consistently. If a needed concept is not
defined there, first decide whether the existing vocabulary already covers it.
Only propose a glossary change when the product has genuinely introduced a new
formal term.

Read relevant records under `docs/adr/` when that directory exists. If an
existing decision conflicts with proposed work, report the conflict rather than
silently choosing one version.

Repository product and documentation ownership rules remain in `AGENTS.md`,
`DEVELOPMENT.md`, and `docs/design/README.md`.
